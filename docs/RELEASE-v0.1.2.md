# Meshport v0.1.2

新增按订阅 DNS 覆写与 Web 管理工具，修复国内服务器全部节点因海外 DNS 无法直连而测试失败的问题。

## 项目更新内容

- **DNS 覆写**：按订阅独立保存解析上游、引导 DNS、节点域名 DNS，提供国内 DoH、Cloudflare / Google、系统 DNS 预设。关闭覆写恢复订阅原配置。
- **TUN DNS 修复**：默认保留订阅 DNS，不再强制替换为海外上游。没有 DNS 的节点列表使用系统 DNS。同时修改 DNS 与开启 TUN 时，超时回滚会恢复原 DNS。
- **代理设置**：新增 IPv6、统一延迟（跟随订阅 / 开启 / 关闭）、内核日志等级。
- **连接管理**：实际连接、累计上传下载、内存，支持本地筛选、每页 20 条和确认后关闭单条或全部连接。
- **实时日志**：打开页面期间收集内核事件，保留最近 300 条，支持暂停和清空，敏感凭证脱敏。
- **界面偏好**：浅色、深色、跟随系统主题，启动页面与代理环境变量格式；仅保存于当前浏览器。
- **维护工具**：内核版本、清空 DNS 缓存、GeoData 更新、脱敏配置查看和诊断导出。
- **代理环境变量**：Bash / PowerShell / CMD 格式，含认证凭证时先确认。浏览器剪贴板不可用时下载脚本。地址为服务器本机 127.0.0.1，供服务器终端使用。
- **加密备份与恢复**：AES-256-GCM、PBKDF2-SHA256（600000 次），独立备份密码。恢复覆盖订阅和代理配置，保留当前管理密码、控制密钥与 Web 端口，并关闭 TUN。
- **测速与手机布局修复**：批次排除 PASS-RULE 等内置项；新增七项导航在手机上可横向滚动，避免整页溢出。

DNS 上游必须从部署服务器可达。IPv6 默认关闭，统一延迟默认跟随订阅，日志默认静默。网站测试仍通过当前模式与规则，不将网页连通性自动视为账号、会员或视频播放解锁。

## 升级与安装

v0.1.1 用户可在设置页检查更新并一键升级，或执行：

```bash
sudo meshport update
```

更新保留数据库、订阅、认证、Mihomo 内核和现有运行配置；管理后台会短暂重启。**升级程序不会立即重写现有 DNS**：遇到该问题时，在设置页选择“国内可直连 DoH”并保存，或保存跟随订阅的 DNS 设置。TUN 待确认时先完成确认；Web 更新前先保存或放弃修改。

新安装或固定安装本版本：

```bash
curl -fsSL https://raw.githubusercontent.com/shushu594088/meshport/main/install.sh | sudo bash -s -- --version v0.1.2
```

支持 Ubuntu / Debian，提供以下文件：

| 文件 | 用途 |
| --- | --- |
| meshport-0.1.2-linux-amd64.tar.gz | x86_64 安装包 |
| meshport-0.1.2-linux-arm64.tar.gz | aarch64 安装包 |
| SHA256SUMS | 安装包 SHA-256 校验 |
| INSTALL-TARGETS.tsv | 系统与架构选择清单 |

v0.1.0 首次升级仍需按原流程保留数据卸载后安装。加密备份不包含内核程序、GeoData、provider 缓存与浏览器偏好；备份密码遗失无法解密。Web 服务不提供托盘、UWP 等桌面专属功能。

## 验证范围

Go 测试、go vet、TypeScript 与生产构建通过；Linux 双架构已交叉编译。9 项浏览器测试通过，另复测 DNS 关闭时保留已保存的有效预设，覆盖手机布局、深色主题、对话框焦点和自动无障碍检查。静态 UI 审计无错误。

GPUserver1 已由管理员部署候选版本并应用国内 DNS，实测 DNS 83 ms，当前代理请求 HTTP 204 / 406 ms，内核 PID 保持不变。逐节点报告保存在服务器 root 目录，本次未直接读取，不宣称所有订阅节点可用。GeoData 更新、关闭实际连接及恢复生产备份未在真实服务器执行；对应流程有自动测试。详见[验证记录](https://github.com/shushu594088/meshport/blob/main/docs/VERIFICATION.md)。
