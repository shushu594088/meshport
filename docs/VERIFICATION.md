Windows amd64 上执行 `go test ./...`、`go vet ./...`、前端 TypeScript 检查及生产构建。新增 Go 测试覆盖诊断认证/节点与目标校验、并发限制、特殊字符节点名、取消、配置变化拒绝、网站状态分类、代理认证与禁止直连回退；更新测试覆盖稳定版筛选、数字版本比较、系统清单匹配、SHA-256 与损坏包拒绝、包路径/链接/重复文件/架构校验，以及健康检查失败后的程序回退。

本机临时 HTTP 后台使用模拟内核/服务，Playwright Chromium 的 7 项测试通过。新增覆盖 25 个节点的跨筛选批量测速、0ms 展示、单项重测、取消、12 网站状态与地区、请求失败、离线状态、更新检查失败/重试、未保存设置阻止更新、对话框焦点/Escape、更新重启断线与重新连接。390px 网站测试页和设置页的 axe 自动检查均无违规；保留桌面、手机和更新页面截图在 build/。frontend premium strict 审计无错误；DESIGN.md lint 无错误，既有 CSS 语义 token 的非阻塞提示仍存在。

新增功能没有在真实 systemd 安装上执行升级，也没有宣称 12 个网站实际全部解锁。网站是否可访问、第三方页面标记是否变化、官方发布包到新版本的真实更新，都需在部署后的目标网络和 Linux 主机验收。本节为 v0.1.1 发布前验证记录；真实 systemd 升级和各网站实际支持范围仍待验收。

## 真实测试环境

Ubuntu 22.04 LTS、amd64、Linux 5.15、systemd、Mihomo v1.19.32。通过 SSH 与授权的 sudo 权限执行测试。

`scripts/acceptance.py` 验证：

- 首次初始化、后续登录、未登录限制及初始化凭证不可重复使用。
- 节点列表模板和完整配置订阅，统一管理入站、端口与 TUN。
- 真实内核启动、停止、重启；节点选择、模式、代理端口、自启状态持久化。
- 重启管理后台时内核继续运行；SIGKILL 内核后后台仍可登录和操作。
- 无效订阅更新保留原运行配置与缓存；移除原已选节点后清除失效选择并提示。
- 删除运行中的当前订阅被拒绝；停止后可以删除。
- HTTP 代理端口冲突保留原配置；Web 端口冲突保留原监听。
- Web 8888 → 8889 → 8888 迁移正常；新端口先启用，旧端口随后关闭。
- 外部代理无凭证时 HTTP 返回 407；恢复仅本机访问正常。
- TUN 开启时 SSH 与 DNS 可用；等待确认期间后台可访问。
- 停止后台后，独立计时器仍在 60 秒窗口到期后恢复旧设置与代理状态；本工具网卡与路由规则得到清理。
- TUN 显式确认、关闭与后续 DNS 正常。

`scripts/lifecycle-test.py` 验证默认卸载保留管理员密码、订阅、设置与自启选项；重新安装正常。明确 `--purge` 删除本工具数据后重新安装，返回待初始化状态。辅助程序拒绝未知命令和多余参数。
