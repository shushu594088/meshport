## 真实测试环境

Ubuntu 22.04 LTS、amd64、Linux 5.15、systemd、Mihomo v1.19.32。通过 SSH 与授权的 sudo 权限执行测试。

`scripts/acceptance.py` 验证：

- 首次初始化、后续登录、未登录限制及初始化凭证不可重复使用。
- 节点列表模板和完整配置订阅，统一管理入站、端口与 TUN。
- 真实内核启动、停止、重启；节点选择、模式、代理端口、自启状态持久化。
- 重启管理后台时内核继续运行；SIGKILL 内核后后台仍可登录和操作。
- 无效订阅更新保留原运行配置与缓存；移除原已选节点后清除失效选择并提示。
- 删除运行中的当前订阅被拒绝；停止后可以删除。
- HTTP 代理端口冲突保留原配置；Web 端口冲突保留原监听。
- Web 8888 → 8889 → 8888 迁移正常；新端口先启用，旧端口随后关闭。
- 外部代理无凭证时 HTTP 返回 407；恢复仅本机访问正常。
- TUN 开启时 SSH 与 DNS 可用；等待确认期间后台可访问。
- 停止后台后，独立计时器仍在 60 秒窗口到期后恢复旧设置与代理状态；本工具网卡与路由规则得到清理。
- TUN 显式确认、关闭与后续 DNS 正常。

`scripts/lifecycle-test.py` 验证默认卸载保留管理员密码、订阅、设置与自启选项；重新安装正常。明确 `--purge` 删除本工具数据后重新安装，返回待初始化状态。辅助程序拒绝未知命令和多余参数。
